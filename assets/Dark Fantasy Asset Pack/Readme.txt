Tileset Info-----:

TILED .tsx file is available in the Tilesets folder, linked to the DarkFantasyTilesetAll.png file. It features terrain sets for path, dirt and water, as well as the animation frames for the water sparkle and lily pad.

The 48x48 version is the same as DarkFantasyTilesetAll.png but upscaled by 3x for rpgmaker compatibility


Object Info-----:

Objects are exported as standard pngs, with animated props (Chests, candles etc.) with each frame as it's own png.


Animation Info-----:

Each animation frame is 48x48 pixels for exporting, but the characters themselves are smaller. The margin is added for VFX, such as in the attack animations.

The aseprite files are included, separated by animation via tag and orientation via layer.
